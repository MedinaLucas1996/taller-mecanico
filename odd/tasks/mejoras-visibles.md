# Feature: mejoras-visibles (five cheap, visible improvements)

Objective: add the five "baratas y con impacto visible" improvements the user picked: customer notice, start-of-session alerts, self-service password change with login lockout, CSV export of the grids, and a printable key tag. Branch `feature/TM-0017` from `feature/TM-0016` at 5457b8c. Delivery strategy: single-pr (user convention: one branch per batch, PR when asked). Test runner: none; checks are a clean `dotnet build` and the off-screen render harness (read paths only).

Style (mandatory for every unit): the professor's event-driven VB.NET: designer-built forms (`.Designer.vb` with `Friend WithEvents`, handlers with `Handles`), SQL inside the form handlers with `Using cn As New MySqlConnection(CADENA)` / `Using cmd`, `AddWithValue` parameters, validation ending in `Exit Sub`, `BeginTransaction` for multi-step saves with `Commit` outside the inner `Try`, short lowercase Spanish comments without accents, role names through `Sesion.ROL_*`, icons through `LeerIcono` (Module Fotos), errors through `MessageBox.Show` or `Errores.MostrarError`. No DAO, no layers, no `AddHandler`, no controls created in code, no new NuGet packages. UI texts in neutral Spanish (the app's language).

## Specs

- S1 Aviso al cliente (`FrmOrdenGestion`). When the order is in `FINALIZADA` and the user is administrador or operador, a button "Avisar al cliente" appears at the foot next to "Imprimir". It builds this text with the order data: "Hola {cliente}, su vehículo {marca} {modelo} patente {patente} ya está listo para retirar. Orden de trabajo N.º {nro}. Servicios realizados: {lista separada por comas}. Total: $ {total aprobado}. ¡Gracias por confiar en nosotros!", copies it to the clipboard, inserts a row in `ot_historial_estado` with the current `id_estado_ot`, `Sesion.IdUsuario` and observacion "Cliente avisado (texto copiado para WhatsApp)", reloads the history and shows "El aviso quedó copiado. Péguelo en WhatsApp o léalo por teléfono al {telefono del cliente, o 'cliente' si no tiene}". Assumption: no external integration; the clipboard is the channel. The mechanic never sees the button.
- S2 Alertas al ingresar (`FrmInicio`, new designer-built form hosted in `FrmPrincipal.panelContenido`). For administrador and operador it replaces the static welcome text and opens automatically after login and after "Inicio" in the menu: greeting "Hola, {NombreCompleto}" with today's date; three cards with counts: "Prometidas para hoy" (fecha_prometida = today and estado not final), "Demoradas" (fecha_prometida < today and estado not final, the same rule as `FrmOrdenes`), "Listas para entregar" (estado `FINALIZADA`); below, a grid with those orders (número, patente, vehículo, cliente, estado, fecha prometida, situación) ordered demoradas first, then prometidas hoy, then listas; and a button "Ir a órdenes de trabajo" that opens `FrmOrdenes` through the main menu. A new menu option "Inicio" at the top of OPERACIONES (visible to administrador and operador) reopens it. The mechanic keeps the current welcome text. Empty state: "No hay órdenes que requieran atención hoy."
- S3 Cambio de contraseña propio y bloqueo del login. (a) `FrmCambiarClave`, new designer-built modal opened from a "Cambiar contraseña" button in the top bar of `FrmPrincipal` (all roles): current password, new password, repeat; the current one is verified with `Seguridad.VerificarClave` against the row of `Sesion.IdUsuario`; the new one must have at least `LARGO_MINIMO_CLAVE` characters (constant moved from `FrmUsuarios` to `Module Seguridad` as `Public Const LARGO_MINIMO_CLAVE As Integer = 6`, `FrmUsuarios` uses it from there) and match the repeat; saved with `GenerarSalt` + `HashearClave` like `FrmUsuarios`; messages: "La contraseña actual no es correcta.", "La contraseña debe tener al menos 6 caracteres.", "Las contraseñas no coinciden.", "Contraseña cambiada." (b) `FrmLogin`: after 5 consecutive failed attempts (any user) the "INGRESAR" button is disabled for 30 seconds and a label shows "Demasiados intentos. Espere {segundos} s" counting down with a designer `Timer`; a successful login resets the counter. In memory only, no schema change.
- S4 Exportar a CSV. New `Module Exportar` with `ExportarGrilla(grilla As DataGridView, nombreSugerido As String)`: `SaveFileDialog` (filter "Archivo CSV (*.csv)|*.csv", suggested name with the date), UTF-8 with BOM, separator `;`, first row = `HeaderText` of the visible columns, then `FormattedValue` of each visible cell with `"` escaped by doubling, and finally "Se exportaron {n} filas a {ruta}". A button "Exportar" next to the existing header buttons in `FrmOrdenes` (the filtered orders grid), `FrmHistorial` (the orders grid of the selected vehicle; disabled while no vehicle is selected) and `FrmMisOrdenes` (its grid). An empty grid shows "No hay filas para exportar." and does not open the dialog.
- S5 Colgante de llaves (`FrmOrdenGestion`). New item "Colgante de llaves" in the "Imprimir" menu, available in every state and to every role (it carries no amounts). A new designer `PrintDocument` + `PrintPreviewDialog` (same pattern as the other reports, `ShowDialog` maximized) draws, at the top-left of the page, a tag of 90 x 50 mm with cut marks: patente very large, "OT N.º {nro}", marca y modelo, cliente, fecha de recepción and fecha prometida (or "sin fecha"), using the `Module Impresion` helpers where they fit. Two identical tags per page (one for the key ring, one for the board).
